# Crain the GOAT Java learning technique

(Springboot/Java - Last updated Nov 2024)
Baeldung is fantastic <https://www.baeldung.com/learn-spring-course>, I normally will do "<Some question> Spring Baeldung", and there is normally a 5-6 step guide on the basic implementation.
I **_strongly_** recommend learning how to navigate Spring's Website <https://spring.io/>. Each of their major projects have fantastic documentation/implementation details.

My typical workflow for learning something in Spring is

1.  Read some Baeldung
2.  Find the Projects from said Article
3.  Attempt to Iterate
4.  Read the Documentation for the Projects
5.  Repeat Steps 3/4 until it works as expected.

You can also find Dan Vega's Recommendation (Java Champion) here <https://github.com/spring-office-hours/resources-learning-spring>, there is a bookmark HTML in this Repo that will be kept up to date by Spring Experts

I haven't had a reason to check it out, but Spring does have the Spring Academy, which is free to use at the time of writing (find it on the website).

Finally after you start to get your footing I'd check out Youtube and the SpringOne Conference talks for a good mix of intro/advanced topics.
